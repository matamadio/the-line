# Security

The Line is a browser game with no accounts, no server and no online data: scores and settings stay in your browser. Still, if you find something that could harm players or the project (for example a way to run code through the game, a leaked key, or a problem in the release or deploy workflows), please report it privately.

## Reporting

Use **[Report a vulnerability](https://github.com/skepticowl/the-line/security/advisories/new)** on the repository's Security tab. Please don't open a public issue for it.

Say what you found, how to reproduce it and what it affects. You'll get an answer as soon as possible; this is a small hobby project, so please allow a few days.

## What is covered

- The game as hosted at <https://skepticowl.github.io/the-line/> and released on <https://skepticowl.itch.io/the-line>.
- This repository's code, workflows and releases.
- The TV apps in `webos/` and `android/`, which only open the hosted game.

Gameplay bugs and unfair difficulty are welcome as normal [issues](https://github.com/skepticowl/the-line/issues/new/choose).
